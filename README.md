An end-to-end SQL project on a real-world quick-commerce (Zepto) product inventory dataset. It covers data exploration, data cleaning, and business-focused analysis to uncover insights on pricing, discounts, stock availability, and revenue potential.

📌 Project Overview

Quick-commerce platforms like Zepto manage thousands of SKUs with constantly changing prices, discounts, and stock levels. This project uses SQL to answer the kind of questions a business or data analyst would be asked:

Which products offer the best discounts?
Which high-value products are frequently out of stock?
Which categories generate the most estimated revenue?
How does pricing vary with product weight?
🎯 Objectives
Explore and understand the structure of the dataset
Clean the data (nulls, invalid prices, unit conversions)
Answer real business questions using SQL
Present clear, actionable insights
🗂️ Dataset
Column	Description
sku_id	Unique ID for each product (SKU)
category	Product category
name	Product name
mrp	Maximum Retail Price
discountPercent	Discount percentage applied
discountedSellingPrice	Final selling price after discount
availableQuantity	Units available in stock
quantity	Pack size / units per item
weightInGms	Product weight in grams
outOfStock	Whether the product is out of stock (TRUE/FALSE)
